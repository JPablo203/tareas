## Instrucciones para correr el proyecto

1. Instalar dependencias:
```bash
npm install
```
2. Configurar la URL del backend:
```bash
export const API_URL = 'http://TU_IP_LOCAL:3000';
```
3.Iniciar la aplicación con Expo: (Asegurarse de estar en el mismo WIFI, si por alguno motivo no funciona usar hotspot)
```bash
npx expo start -c
```
4. Escanear el QR generado usando Expo Go (Verificar que la app "Expo Go" y la generacion de la APP en codigo esten en la misma version SDK)
